Depth Pro 2 S (FP16 ONNX) in the browser with ONNX Runtime Web: WebGPU, else WASM. Metric depth from any photo; the focal length is estimated, or give its field of view or `fx`. Hover the depth map for meters. Unofficial. Weights are for non-commercial research use only ([license](https://huggingface.co/christianengel/DepthPro2-S-ONNX/blob/main/LICENSE)).
